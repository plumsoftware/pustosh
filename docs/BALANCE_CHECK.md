## Итог

Вне цели: 201 из 248 пар «оружие — враг». Элита ×1.5 HP при цели 8–12 против 3–6 у обычных недостижима одновременно (×1.5 от 3–6 = 5–9): либо поднять elite.hpMul до ~2.2, либо принять 5–9 для элиты. Решение — за владельцем, числа в данных не менялись.
