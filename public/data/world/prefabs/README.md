# Префабы мира (шаг 3)

Формат: `plan` — строки клеток сверху вниз: `#` стена, `D` дверь, `O` окно, `.` пол комнаты, `,` расчищенная земля (без объектов), пробел — земля как сгенерирована.
`material` — материал стен (`building.json → materials`), без него — по биому из `worldgen.json → ruins.materials`.
`objects[].at` — точка основания объекта в клетках от левого верхнего угла плана (дробные можно).
Ссылка на объект: `station` (+ `state` из `stateSprites`), `container` / `furniture` (id из `biomes.json → common` или `random`), `object` (id объекта текущего биома или `random:<kind>`), `sprite` (путь к картинке + `kind` для коллайдера).
`anchor` — клетка плана, которая ставится в точку размещения.
Арена: `clearRadiusTiles`, `ring` (кольцо объектов вида `kind`), объекты от центра. Ворота: `sprite`, `spanExtraTiles` — сколько клеток добавить к ширине дороги.
