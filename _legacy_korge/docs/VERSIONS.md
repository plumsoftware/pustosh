# Версии

Проверено 27.10.2026. Стек утверждён владельцем: KorGE.

| Что | Версия | Комментарий |
| --- | --- | --- |
| KorGE | 6.0.0 | последний релиз (Maven Central, 16.05.2025); Gradle-плагин `com.soywiz.korge` |
| Kotlin | 2.0.20 | зафиксирован KorGE 6.0.0, отдельно не поднимать |
| kotlinx.serialization-json | 1.7.1 | как в KorGE 6.0.0 |
| Gradle | 8.10 (wrapper) | как в репозитории KorGE |
| JDK для сборки | 21 | на JDK 25 Gradle 8.10 не запускается |
| Android Gradle Plugin | 8.2.2 | приходит вместе с плагином KorGE |
| Android minSdk | 24 | по ТЗ |
| Android compileSdk / targetSdk | 35 | AGP 8.2.2 официально проверен до 34 — при сборке печатает предупреждение, сборка и запуск на API 35 проверены |
| JVM target | 21 | KorGE 6 собирает JVM и Android под 21; `core` и `platform` — так же |

## Что проверено

- Официальный шаблон `korge-hello-world` и этот проект собираются под jvm, js и android.
- Веб-сборка запускается в Chrome (WebGL 2), Android-сборка — на эмуляторе API 35.

## Открытые вопросы

- Требование RuStore к `targetSdk` в официальных источниках не найдено. Если потребуется 36+, нужен более новый AGP — проверить совместимость с KorGE до релиза (шаг 10).
- KorGE не выпускал релизов с мая 2025 (коммиты в репозитории идут). Следить за выходом новой версии.
