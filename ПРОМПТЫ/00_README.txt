ПРОМПТЫ ДЛЯ CHATGPT — НЕДОСТАЮЩИЕ КАРТИНКИ «ПУСТОШИ»
=====================================================

10 листов. Каждый файл 01–10 — один лист (одна картинка с сеткой объектов).
В каждом файле:
  1) что приложить к сообщению (картинки-образцы из пакета);
  2) готовый промпт на английском — копировать целиком, между строками ===== PROMPT =====;
  3) список имён ячеек по порядку — по нему лист режется на PNG (tools/cutter.py).

ПРАВИЛА, КОТОРЫЕ УЖЕ ПРОВЕРЕНЫ НА ЭТОМ ПАКЕТЕ (tools/PROMPT_TEMPLATE.md):
  - Фон сплошной #FF00FF (пурпурный). Эффекты — чёрный #000000. Если объект сам розовый/фиолетовый — #0000FF.
  - Никаких теней на земле, подложек травы/песка/снега, дыма, огня, тумана, ореолов, текста, цифр, логотипов.
  - Стекло непрозрачное, тонкие детали — толще волоса.
  - Одна ячейка = один объект, по центру, поля не меньше 12%, объекты не касаются друг друга.
  - Если ChatGPT теряет детали или путает порядок — попросить «Draw ONLY rows 1–2», потом остальные ряды отдельным листом.
  - Перед отправкой проверить: порядок ячеек совпадает со списком имён, все объекты в одном ракурсе.
