Файл листа: s34_ui_kit.png      Папка нарезки: ui/kit/
Зачем: сейчас кнопки, вкладки, панели и полосы собраны из нескольких старых деталей
(button_plate, panel_9slice, slot, bar_frame) — у кнопок нет состояний «нажата/неактивна»,
нет ползунков громкости, флажков, полос прокрутки, вкладок, курсора. Один лист — единый стиль.
Приложить: 1) source_sheets/s23_ui.png (стиль: ржавый металл, заклёпки, мешковина),
2) скриншот игры (любой, с HUD) — чтобы цвета сочетались с картой.
Размеры в игре: кнопки 9-slice (тянутся), иконки 64×64, курсор 32×32.

ВАЖНО для 9-slice: у всех плашек и панелей углы с заклёпками, а середина и края — РОВНЫЕ,
без рисунка по центру, чтобы их можно было растягивать.

===== PROMPT =====
TWO ATTACHED IMAGES: image 1 = the UI style reference of this game (riveted rusty metal plates, burlap panels, round metal buttons). Image 2 = a screenshot of the game for color harmony.

ART STYLE — follow image 1 strictly. A complete user-interface kit for a mobile post-apocalyptic survival game: painted semi-realistic look, worn rusty steel with rivets, olive and dark-brown painted metal, burlap/canvas inlays, chipped paint, scratches. Warm muted palette: olive green, rust orange, dark brown, bone white, with small accents of warm amber (active/selected) and dull red (danger). Soft light from the top-left. All elements flat-on, seen straight from the front, no perspective.

9-SLICE RULE — critical: every plate, panel, bar frame and tab must have decorated CORNERS (rivets, bolts, bent metal) but PLAIN, EVEN, UNIFORM edges and center (no logos, no big scratches or patterns in the middle) so they can be stretched in the game without visible distortion.

BACKGROUND AND EDGES — critical: perfectly flat solid magenta #FF00FF. No shadow on the background. Hard, clean, fully opaque edges. Every element separate, none touching.

FORBIDDEN: text, letters, numbers, words on buttons, logos, real brands, watermark, grid lines, labels.
