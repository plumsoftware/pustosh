# Журнал изменений

## Переход на стек пакета ТЗ 3.0 — 28.10.2026

Пакет ТЗ 3.0 (`Pustosh_GameDev_Package 2`) меняет стек с Kotlin + KorGE на **TypeScript + Phaser 3 + Vite + Capacitor**. Прежняя реализация шагов 1–2 на KorGE перенесена без изменений в `_legacy_korge/` (не удалена; git в папке нет). Dev-ключ подписи перенесён в `keystore/dev.keystore`. Шаги 1 и 2 выполнены заново на новом стеке.

## Шаг 1. Каркас, сборки, платформенный слой — 28.10.2026

### Сделано

- Vite + TypeScript strict, структура по `TZ/00_OVERVIEW.md §3`. Версии — `docs/VERSIONS.md` (TypeScript 6.0.3, а не 7: его не поддерживает typescript-eslint).
- ESLint + Prettier: в `src/core` запрещены `phaser`, `@capacitor/*`, импорт `game`/`platform`, `window`/`document`/`localStorage`/`navigator`/`performance`, `Date.now`, `Math.random`. Правило проверяет тест `tests/eslint-core.test.ts`.
- Режимы `VITE_PLATFORM` = `dev | yandex | android`, `main.ts` выбирает площадку динамическим импортом (в сборку попадает только нужная). Для `yandex` `index.html` получает `<script src="/sdk.js">` до бандла (Vite-плагин), `base: './'`. Архив `dist-yandex.zip` — `tools/zip-dist.ts`.
- CSS: чёрный фон, канвас на весь экран, `touch-action/user-select/overscroll-behavior: none`, `-webkit-touch-callout: none`, контекстное меню отключено.
- Phaser 3.90: `AUTO` (WebGL с тихим откатом на Canvas), `RESIZE` (поле до краёв), `antialias`, `roundPixels`. Сцены Boot → Preload (полоска) → MainMenu («Играть», «Настройки») → World (серый фон, маркер двигается по тикам) + UI → Pause (Esc / кнопка / «Назад»).
- Отладочный оверлей: F1 или тройной тап в левом верхнем углу (FPS, тики, площадка, устройство, язык, причины паузы, рендер, версия).
- `PlatformServices` и сервисы — ровно сигнатуры из ТЗ (`src/platform/PlatformServices.ts`). Кнопка «Назад» — отдельный необязательный интерфейс `BackButtonSource`, чтобы не менять основной.
- `DevPlatform`: окно «РЕКЛАМА (заглушка)» на 2 с (DOM), сохранения в `localStorage`, покупки всегда успешны. Реклама соблюдает точки показа и интервал из `balance.json`, учитывает `remove_interstitials`.
- `YandexPlatform`: `YaGames.init()` в try/catch, без SDK — `Yandex SDK not found, stub mode`; `LoadingAPI.ready()`, `GameplayAPI.start/stop`, `game_api_pause/resume` → пауза `PLATFORM`.
- `AndroidPlatform`: сохранения через `@capacitor/preferences`, `appStateChange` → `PLATFORM`, «Назад» → меню паузы, `StatusBar.hide()`.
- `GameClock` (50 мс, причины паузы, обрезка длинного кадра, слушатели), `PlatformConfig` (ветка `balance.json` по площадке, разворачивает `"as yandex"`, `mvpBiomeLimit = 3`), `log` с уровнями (в релизе warn), RNG mulberry32.
- Пауза: вкладка/фокус → `TAB_HIDDEN`, площадка → `PLATFORM`, реклама → `AD` (`AdsController`), меню → `MENU`, галерея → `DIALOG`. Любая пауза глушит звук (`AudioBus`) и останавливает `WorldScene`.
- **Только горизонтальная ориентация:** Android — `sensorLandscape`; в мобильном браузере — экран «Поверните устройство горизонтально» и пауза `ORIENTATION` (новая причина) + попытка `screen.orientation.lock('landscape')`.
- Android-оболочка Capacitor 8 (`android/`), `tools/patch-android.ts`: ориентация, полный экран, аппаратное ускорение, подпись (dev-ключ или `RELEASE_*`). Собраны debug/release APK и AAB.
- `StressScene` и замер — `docs/PERF_BASELINE.md`.

### Проверено

- Браузер ПК (Chrome): меню → «Играть» → реклама-заглушка (`AD`, звук выключен) → мир (тики идут) → Esc (`MENU`, тики стоят) → продолжить; скрытие вкладки и потеря фокуса → `TAB_HIDDEN`, возврат снимает паузу.
- Телефон Xiaomi 24048RN6CG, APK: альбомно на весь экран, «Назад» → меню паузы, сворачивание → `TAB_HIDDEN` + `PLATFORM`, возврат — игра идёт. В мобильном Chrome в портрете — экран «Поверните устройство».
- Стресс-сцена: ПК 60 FPS; слабый Android в APK — 60 FPS при рендере 1x.
- `npm test` (28 тестов), `npm run lint`, `npm run typecheck`, `build:yandex`, `build:android` + Gradle — без ошибок.

### Отложено / отклонения

- Промпт шага просил показать версии и дождаться подтверждения — версии выбраны сразу (см. `docs/VERSIONS.md`), их можно поменять.
- **appId** временный — `ru.pustosh.game` (ТЗ: `ru.<владелец>.pustosh`), нужно решение владельца.
- Реальные реклама, покупки, облачные сохранения Яндекса и RuStore — шаг 10.
- Замер в **Яндекс Браузере** на телефоне (не установлен) и на iPhone (нет устройства) — владельцу.
- Панель навигации Android видна (нет immersive-режима): скрыть её можно только нативным кодом в `MainActivity` или плагином — решить к релизу.
- В консоли Яндекса в настройках черновика стоит указать горизонтальную ориентацию — тогда площадка сама попросит повернуть телефон.
- Свой шрифт и UI на спрайтах `ui` — следующие шаги, сейчас системный шрифт и простые кнопки.

### Известные проблемы

- На слабом телефоне рендер в физическом разрешении (rs 2) даёт ~30 FPS, поэтому по умолчанию rs 1: спрайты на телефонах немного мягче, текст чёткий (`TEXT_RES`). Варианты — `docs/PERF_BASELINE.md`.
- На паузе по `blur` Phaser сам приостанавливает аудиоконтекст, и геттер `game.sound.mute` может отставать; состояние звука смотреть по `AudioBus.isMuted`.

## Шаг 3. Мир: генерация, тайлы, объекты, камера, день и ночь — 28.10.2026

### Сделано

- **Модель мира** (`src/core/world`): `World` (сид, чанки 32×32, кэш с LRU, выгрузка), клетка — тайл, биом, слой (земля/вода), проходимость, стена/дверь/окно, пол, комната. `WorldObject` — стабильный `uid`, источник (объект биома, контейнер, мебель, станок, префаб), состояние, коллайдер, свечение, свет, требование трофея.
- **Дельта**: `setObjectState` / `removeObject` / `addObject` пишут только изменения; `exportDelta()` — только изменённые чанки, `importDelta()` применяет их при генерации. Выгруженный чанк возвращается с изменениями.
- **Генерация по сиду** (`WorldLayout`): кольца по `biomeRingsRadiusTiles` с рваной границей (шум Перлина ±6 клеток), за краем — море. Тайлы — смесь по шуму (`worldgen.json → tileMix`), в болоте — лужи. Три дороги от края к центру (грунтовка в пригороде, асфальт с разметкой дальше; вертикальные участки — повёрнутый тайл). Объекты — сетка с джиттером, плотность по видам, деревья гуще у края кольца, обломки машин вдоль дорог, «посёлки» с постройками. Ничего не ставится на дороги, в префабы и рядом со стартом.
- **Префабы** (`public/data/world/prefabs/*.json`, формат — README там же): бункер старта (кольцо 1, юг; горящий костёр), 4 руины (8–12 на биом, материал стен по биому, мебель и контейнеры из `biomes.common`), арена босса в каждом кольце (расчистка 9 клеток, кольцо камней, костёр-чекпоинт), ворота на каждой дороге при переходе в следующее кольцо (снимаются трофеем босса этого кольца).
- **Рендер**: тайлсет земли собирается кодом из атласа (база + 15 масок «мягкого края» на тайл); слой тайлов на чанк (база + 2 слоя краёв), вода — отдельная анимированная текстура. Объекты с Y-сортировкой, тени (эллипс 22%), стены по `assembly_rules` (верх + лицо, двери, окна), пол комнат чуть темнее верха стен. Перекрытие героя: объект перед ним плавно уходит в альфу 0.45 за 0.15 с; южная стена комнаты — 0.35, пока герой внутри.
- **Камера**: плавное следование (lerp 0.15), края мира, в кадре ~16×9 клеток на ПК и ~11×6 на телефоне, колесо — зум 0.75–1.25.
- **Коллизии** (`Collision.ts`): круги и прямоугольники основания по виду объекта (`worldgen.json → colliders`), стена — клетка + лицо под ней, море непроходимо; пространственная сетка; скольжение вдоль препятствий.
- **День и ночь** (`core/systems/DayNight.ts`): рассвет / день / закат / ночь, номер дня, кровавая ночь каждую 7-ю. Маска света — RenderTexture в половину экрана: ночь тёмно-синяя 85%, закат тёплый, кровавая ночь красная с пульсом; мягкие круги света вокруг героя, костров, фонарей и светящихся объектов. На телефоне маска стоит 0.7 мс.
- **Анимации** (ANIMATIONS §0, §4, §5, MVP): ветер для деревьев, травы и кустов (+ дыхание кустов), течение воды и блики, пульс свечения (ночью ярче), перекрытие героя, смена суток, ночь, кровавая ночь, пламя костра. Общие приёмы §0 — `src/game/render/Fx.ts`. **Галерея анимаций — F7** (20 пунктов).
- **Отладка**: F3 — свободная камера, границы чанков, коллайдеры, биом и тайл под курсором; F4 — время ×10; F5 — карта всего мира с телепортом по клику. Временный «герой» — `ref_idle`, стрелки/WASD.
- HUD: день, время суток, фаза, кровавая ночь.

### Найдено и исправлено по ходу замеров на телефоне

- Phaser не отсекает объекты за кадром: рисовались все ~20 удерживаемых чанков. Теперь видимы только чанки в кадре (+ запас для высоких спрайтов).
- Сборка вида чанка трогала соседние чанки и синхронно генерировала их (пики 67 мс). Теперь данные генерируются на шаг дальше видов, а виды строятся порциями в бюджете 6 мс за кадр.
- Свечение в режиме ADD между обычными спрайтами рвало пакеты отрисовки: в центре мира 11 FPS. Все свечения теперь на одной глубине (один пакет) — 56–59 FPS. Цена: свечение рисуется поверх объектов, рядом с грибом слегка подсвечивается и герой.

### Отложено

- Кольца пока не замкнуты: пройти в следующий биом можно в обход ворот. Непроходимую границу (обрыв, завал, забор) нужно согласовать с владельцем — геймплей шагов 8–9.
- Вход в здания-фасады (`apartment_entrance`, `shop_front`…) и интерьеры — со строительством/лутом.
- Мельница, перекати-поле, пар, дым, флаги (приоритет «+») — позже.
- Буря, метель, радиационная дымка, дождь — `later` по каталогу.
- Сохранение дельты мира в слот — с системой сохранений (шаг 9); API и тесты готовы.

### Известные проблемы

- При **первой** за сессию догрузке атласа биома 2–6 на телефоне один кадр длится ~90–120 мс: Phaser загружает текстуру в GPU разом. Варианты: заранее догружать атлас соседнего кольца, когда герой подходит к границе; делить ленивые атласы на листы по 1024 px.
- На телефоне в углу видна подсказка «Esc — пауза» — HUD для сенсорного ввода будет на шаге 4.

### Доработка шага 3 по решениям владельца — 28.10.2026

- **Граница колец — забор** (решение владельца). Клетки внутреннего кольца на границе с внешним становятся забором (`WALL_FENCE`, непроходим); на диагональных стыках добавляется клетка, чтобы не было щелей «в угол». Материал по границе — `worldgen.json → ringFences.materials` (пригород → болото: доски … тундра → эпицентр: бетон). На дорогах забора нет — там ворота. Тест: заливка от старта с учётом ворот не попадает во второе кольцо. Отрисовка — секции `fence` рядами на всю клетку.
- **Атласы биомов заранее и выгрузка.** Атлас биома догружается, когда биом ближе 56 клеток к камере, и выгружается дальше 112 клеток, если его не использует ни один построенный чанк (`worldgen.json → atlasStreaming`). Ленивые атласы грузятся через `fetch` + `createImageBitmap`: PNG декодируется вне главного потока, загрузка в GPU на телефоне — **4 мс вместо 65–76 мс**.
- **Дроп и ящики переживают выгрузку.** Выброшенный предмет хранится в дельте мира и лежит `worldgen.json → persistence.droppedItemLifetimeSec` = 600 игровых секунд (10 минут), даже если чанк или атлас выгружены, и попадает в сохранение. Содержимое ящика после первого открытия хранится в дельте до респауна — `balance.json → world.lootRespawnGameDays` (3 игровых дня); потом ящик снова закрыт и наполнится заново. API: `World.dropItem / pickUp / openContainer / setContainerContents / containerContents / update(now)`; рендер убирает исчезнувшее и обновляет ящики. Отладка: **F6** — выбросить случайный предмет у героя. Инвентарь и таблицы лута — шаг 5.
- **Часто меняющийся текст — растровым шрифтом** (`ui/BitmapFont.ts`, глифы рисуются кодом при запуске): часы HUD, отладочный оверлей, отладка мира, стресс-тест. Обычный `Text` перезаливает текстуру в GPU при каждом изменении.

| Сценарий | Результат |

#### Ложная тревога про память

Лог видеодрайвера PowerVR (`AllocateTextureMemory … Texture memory is N`) показывал рост до 2.9 ГБ — больше, чем вся память телефона (2.8 ГБ). Это накопительный счётчик выделений, а не занятая память: PSS процесса стабилен (~100 МБ), свободно ~700 МБ. Утечки нет; для проверки памяти на телефоне смотреть `dumpsys meminfo`, а не этот лог.

#### Известные проблемы

- На скорости транспорта (шаг 9) при въезде в новый ряд чанков внутренних колец — редкие кадры 60–90 мс. Варианты: строить виды на 2 чанка вперёд по направлению движения, объединить слои краёв тайлов в один, рисовать тайлы чанка заранее в текстуру.

## Правки после игры владельца — 28.10.2026

- **«Собрать» и «Удар» разделены.** Кнопка действия (E на ПК) — только добыча и открытие (подпись «Собрать»/«Открыть», без цели кнопка приглушена, подсказка «Нечего собрать»); кнопка удара (ЛКМ на ПК) — только бой, даже если перед героем дерево. Удержание у каждой кнопки своё. На кнопке действия — иконка инструмента в руке или рука, кулака там больше нет.
- **Удар без «вентилятора».** Замах сверху был полным оборотом руки на 360° (`Animations.overhead`) — теперь рука поднимается вперёд-вверх над головой, бьёт вниз перед собой и возвращается (дуга ~170°).
- **Бег от стика.** Ходьба — в пределах основания стика (сила до 1 на краю); бег — если оттянуть палец дальше, за кольцо бега (×1.4 радиуса). Кольцо видно вокруг стика, при беге оно и ручка оранжевые, над стиком — «Бег».
- **Мир ×2**: `balance.json → world.sizeTiles` 512 → 1024, `biomeRingsRadiusTiles` ×2 (512/420/330/240/160/80); `worldgen.json`: старт на радиусе 464, руин 24–36 на биом (было 8–12), посёлков 8 на кольцо (было 3), шум границы колец 10/70 (было 6/40). Раскладка мира строится за ~80 мс.
- Найдена и закрыта дыра в заборе между кольцами: на диагональном переезде широкая дорога обходила ворота. Теперь клетки дороги на границе, не перекрытые створками ворот, закрываются забором.
- Сохранения хранят размер мира: сохранение маленького мира не загружается в новый — игра начинается заново у бункера с сообщением.
