# Шаг 3. Мир: генерация, тайлы, объекты, камера, день и ночь

## Цель

Бесшовный мир 512×512 тайлов из 6 биомов-колец, подгружаемый чанками вокруг камеры. Объекты расставлены, правильно перекрывают друг друга (Y-сортировка), имеют коллизии. Работают день, ночь и освещение.

## Входные данные

- `data/biomes.json` (кольца, тайлы, объекты), `data/balance.json → world, dayNight`.
- Атласы `tiles`, `walls`, `biome1..6`, `interior_defense` из шага 2.
- GDD §3, §5.

## Задачи

### 3.1. Модель мира (`core/world`)

1. `World(seed)`, `Chunk(cx, cy)` 32×32 клетки. Клетка хранит: тип тайла (индекс), высоту-слой (0 — земля, 1 — вода), флаг «проходимо», ссылку на объект-постройку (если есть).
2. Объекты мира (`WorldObject`): id определения, позиция (в тайлах, float), состояние (целый/добытый, HP, время восстановления), коллайдер.
3. Сохраняются **только изменения** чанка относительно генерации (дельта): срубленные деревья, открытые ящики, постройки. Неизменённые чанки не сохраняются.

### 3.2. Генерация по сиду

1. Биом клетки: расстояние от центра карты → кольцо по `balance.world.biomeRingsRadiusTiles` (`[256,210,165,120,80,40]` = внешние радиусы колец 1…6). Граница колец «рваная»: шум Перлина/Симплекса амплитудой ±6 тайлов.
2. Тайл: внутри биома — смесь его тайлов (`biomes[n].tiles`) по второму шуму (пятна травы, грунта; в болоте — лужи `water_shallow`; в пустыне — пятна глины). Дороги: 2–3 трассы, проходящие через все кольца к центру, — `dirt_road_h` в пригороде, асфальт дальше. Плавные переходы между тайлами — маской-градиентом в шейдере или полупрозрачными «краями» (сгенерировать в коде из соседнего тайла).
3. Объекты: по сетке Пуассона/джиттера, плотность по типу (`tree` гуще у края кольца, `rock` равномерно, `vehicle_wreck` вдоль дорог, `building_poi` — в узлах-«посёлках»). Не ставить на дороги и в радиусе 3 тайлов от точки старта.
4. **Префабы** (фиксированные точки): бункер старта (кольцо 1, юг), 8–15 руин на биом (комнаты из стен материала биома + мебель + контейнеры из `biomes.common`), арены боссов (кольца 1–6), ворота между кольцами (препятствие, которое снимает трофей босса). Описание префабов — JSON `world/prefabs/*.json` (агент создаёт): размеры, стены, двери, расстановка мебели и лута.
5. Детерминированность: один сид → один мир; юнит-тест сравнивает хеш чанков (0,0), (5,5), (8,8) между двумя запусками.

### 3.3. Рендер

1. **Слой тайлов**: только видимые чанки + 1 по краям; рисование пакетами (один draw call на атлас).
2. **Слой объектов**: всё, что стоит на земле (объекты, стены, персонажи, враги, дроп), сортируется по Y основания каждый кадр (или при движении). Стены рисуются по правилам `building.json → assembly_rules`.
3. **Прозрачность перекрытия**: если герой оказался за деревом/зданием, объект перед ним становится полупрозрачным (альфа 0.45) — проверка пересечения прямоугольника героя со спрайтом объекта, у которого Y основания больше Y героя.
4. **Тени**: под каждым объектом и персонажем — эллипс тени (чёрный 22% альфы), размер от ширины спрайта.
5. **Камера**: следует за героем с плавностью (lerp 0.15), ограничена краями мира, зум 0.75–1.25.

### 3.4. Коллизии

Простые формы: круг у основания для деревьев/камней/персонажей, прямоугольник основания для машин, мебели, станков; клетка целиком для стен. Пространственная сетка (хеш по клеткам) для быстрых запросов. Скольжение вдоль препятствий.

### 3.5. День, ночь, освещение

1. `DayNightSystem`: время суток 0–720 c, фазы `DAY`, `DUSK`, `NIGHT`, `DAWN`, номер дня, флаг кровавой ночи (каждая 7-я).
2. Освещение: оверлей-маска поверх мира. Днём прозрачный, на закате тёплый тон, ночью тёмно-синий 85% с «дырами» света: круг вокруг героя (радиус от фонаря), костры, лампы, прожекторы (конус), светящиеся грибы и радиация (зелёные). Свет — мягкий радиальный градиент, без резкого края. Кровавая ночь — красноватый оттенок.
3. Освещение должно стоить ≤ 2 мс кадра на телефоне: рендер маски в текстуру пониженного разрешения (1/2 или 1/4) и растяжка.

### 3.6. Отладка

Свободная камера (F3), показ границ чанков, коллайдеров, номера биома под курсором, ускорение времени ×10 (F4), телепорт по карте (F5).

## Критерии приёмки

- [ ] При полёте камерой по всему миру нет подвисаний > 50 мс при подгрузке чанков; память стабильна (чанки выгружаются).
- [ ] Кольца биомов узнаваемы, границы не идеальные круги; дороги идут к центру.
- [ ] Герой-эталон (`hero.ref_idle`, временно как спрайт) заходит за дерево — дерево полупрозрачное; выходит перед деревом — дерево рисуется за ним.
- [ ] Руины-префабы: комнаты со стенами без щелей на углах, двери, мебель внутри; южная стена комнаты полупрозрачна, когда «герой» внутри.
- [ ] Ночь выглядит как мягкий тёмный оверлей с кругом света, без резких краёв; костёр в префабе бункера светится.
- [ ] Один сид даёт одинаковые чанки (юнит-тест).
- [ ] FPS ≥ 60 на ПК, ≥ 45 на среднем Android при максимальной плотности объектов в кадре.

## Не делать на этом шаге

Героя с управлением (пока — спрайт `ref_idle`, двигаемый стрелками для проверки), врагов, добычу.
