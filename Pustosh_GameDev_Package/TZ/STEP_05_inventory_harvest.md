# Шаг 5. Инвентарь, добыча, инструменты, лут, подсветка находок

## Цель

Мир становится ресурсом: игрок рубит, копает, откручивает, обыскивает контейнеры, подбирает дроп. Есть инвентарь, пояс, сундуки, прочность, подсветка ближайших интересных объектов.

## Входные данные

- `data/items.json`, `data/biomes.json` (`objects[].harvest`, `common.loot_containers`, `common.furniture_salvage`), `data/balance.json → player, world`.
- `assets/icons/*`, `assets/replacements/*`, `assets/ui/slot*`, `assets/effects/spark_*`, `dust_*`, `sparkle_*`.
- GDD §6–7, §14.

## Задачи

### 5.1. Инвентарь (`core/inventory`)

1. `ItemStack(itemId, count, durability?, mods[])`, `Inventory(slots)`: добавить (с автостаком), забрать, переложить, разделить стак, проверить наличие набора ресурсов, атомарно списать набор (для крафта).
2. Игрок: 20 слотов + рюкзак (`extraSlots`), пояс 6 слотов, экипировка: голова, тело, ноги, обувь, рюкзак, + выбранный предмет пояса в руке.
3. Перегруз: нельзя подобрать, если места нет (всплывающее «Нет места»).
4. Сундуки: инвентарь объекта, UI «два окна» (игрок ↔ сундук), кнопка «Сложить похожее» — переносит все стаки, которые уже есть в сундуке.
5. Юнит-тесты: стаки, атомарное списание, разделение, перенос.

### 5.2. Добыча (`core/systems/Harvest`)

1. Цель — ближайший объект с `harvest` в радиусе 1.2 тайла перед героем (сектор 90°).
2. Удар инструментом: если `tool.toolType == harvest.tool` и `tool.harvestTier >= harvest.minTier` → прогресс `+1 × gatherMultiplier`; иначе — прогресс ×0.25 и двойной износ, подсказка «Нужен <инструмент> тир N». Руки (`hands`) работают для `minTier 0`.
3. Каждый удар: анимация `gather`, тряска объекта (сдвиг ±2 px, 0.1 с), частицы по типу (дерево — `dust` бурым тинтом, камень — `spark` серым, металл — `spark`), износ инструмента −1, выносливость −`staminaPerUse`.
4. После `hits` ударов: выпадает дроп (`drops` — диапазоны min..max), объект меняет спрайт на `afterHarvest` или исчезает; время восстановления `resourceRespawnGameDays` (случайно в диапазоне), кусты отрастают через 2 дня.
5. Дроп лежит на земле предметами: подпрыгивает при появлении, светится рамкой редкости (тир 0–1 серый, 2 зелёный, 3 синий, 4–5 фиолетовый, 6 оранжевый), подбирается автоматически в радиусе `pickupRadiusTiles` (или по кнопке на ПК).
6. Мебель в руинах разбирается (`common.furniture_salvage`) молотком/ключом/ножом.

### 5.3. Контейнеры и лут

1. Контейнеры из `common.loot_containers`: при открытии — UI сундука с содержимым из таблицы лута (`table`). Таблицы лута (агент создаёт `data/loot_tables.json`, согласовав с владельцем): `general`, `military`, `tools_clothes`, `clothes`, `food`, `rare`, `survivor`, `medicine`, `junk`; вес предметов зависит от биома (тир ≤ биом+1).
2. Ящики меняют спрайт на «открытый» (`crate_wood_open`, `crate_military_open`), остальные — гаснут (тинт 70%).
3. Обновление лута раз в `lootRespawnGameDays`.
4. **Точка рекламы за награду `double_loot`**: кнопка «×2 (реклама)» в окне контейнера (не чаще 1 раза в 5 минут).

### 5.4. Прочность и починка

Шкала прочности под иконкой; на 0 — значок поломки, эффективность 50%. Ремкомплект (`repair_kit`) на верстаке восстанавливает 50% (позже навык Инженера). **Точка рекламы `repair_all`** — в меню инвентаря «Починить всё (реклама)».

### 5.5. Подсветка находок (`game/render/Highlight`)

1. В радиусе `highlightRadiusTiles` (навык расширяет) у интерактивных объектов — мягкий контур: белый — добываемое, жёлтый — контейнер с лутом, синий — записка/чертёж; обысканное/добытое — без контура.
2. Контур — шейдер обводки по альфе спрайта (2 px, мягкий) с пульсацией яркости 1.5 с; fallback без шейдеров — увеличенная копия спрайта с тинтом под объектом.
3. Ближайшая цель действия — контур ярче + иконка действия над ней.

### 5.6. UI инвентаря

Экран «Инвентарь + персонаж»: слева манекен героя (риг в позе idle) со слотами экипировки, справа сетка слотов (`ui/slot`, выбранный — `ui/slot_selected`, рамка редкости по тиру), снизу пояс. Перетаскивание (мышь/палец), долгий тап — меню (использовать, разделить, выбросить, починить). Подсказка предмета: имя, тир, параметры, прочность. Панели — `ui/panel_9slice`, кнопки — `ui/button_plate_9slice`, закрытие — `ui/btn_close`.

## Критерии приёмки

- [ ] В пригороде можно руками собрать ветки, волокно и камни, скрафтить (временно — читом) каменный топор и срубить сосну: 5 ударов, выпадает 4–6 древесины, остаётся пень.
- [ ] Каменной киркой медную руду не добыть: подсказка про тир, двойной износ.
- [ ] Машина разбирается гаечным ключом, превращается в остов (`car_frame`).
- [ ] Ящик открывается, меняет спрайт, содержит лут по таблице; через 3 игровых дня снова полон.
- [ ] Подсветка видна только в радиусе 4 тайлов, цвета соответствуют типам.
- [ ] Инвентарь, сундук и «сложить похожее» работают; юнит-тесты инвентаря проходят.
