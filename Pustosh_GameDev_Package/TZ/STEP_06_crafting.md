# Шаг 6. Крафт, станки, книга рецептов

## Цель

Работающая цепочка «ресурс → станок → предмет»: крафт руками, установка станков, фоновая работа станков с очередью, книга рецептов с тремя состояниями и подсказками, где добыть недостающее.

## Входные данные

- `data/recipes.json` (149 рецептов), `data/stations.json` (23 станка), `data/items.json`, `data/skills.json` (поле `requiresSkill`).
- Спрайты станков `assets/world/interior/*`, эффекты `flame_*`, `smoke_*` для костра/горна/плавильни.
- GDD §7.

## Задачи

### 6.1. Логика крафта (`core/systems/Craft`)

1. `CraftService.canCraft(recipe, sources)`: ресурсы ищутся в инвентаре игрока **и в сундуках в радиусе 4 тайлов** от станка (удобство мобильной игры).
2. `start(recipe)`: атомарно списать ресурсы → поставить задание в очередь станка (до 5), время `timeSec` (× бонус навыка `engineer` «Конвейер»). Крафт руками — мгновенно (≤ 3 с с полоской).
3. Готовое: кладётся в «выход» станка (до 10 стаков); над станком — значок готовности; если выход полон — станок ждёт.
4. **Фоновая работа**: прогресс считается по игровому времени. При загрузке чанка со станком — «догнать» прогресс за прошедшее время. Работает, даже если игрок далеко.
5. Станки с топливом/питанием: костёр, горн, плавильня потребляют топливо (`wood`, `coal`, `peat`) — слот топлива в UI станка; электростол и электроловушки работают только в радиусе генератора с топливом (`generator.powerRadiusTiles`).
6. **Точка рекламы `instant_craft`**: в окне станка кнопка «Завершить сейчас (реклама)» для текущего задания дольше 30 с.
7. Юнит-тесты: списание, очередь, догон по времени, топливо, ресурсы из соседних сундуков.

### 6.2. Открытие рецептов

`unlock` в рецептах:
- `known` — доступен сразу, если станок есть;
- `tutorial` — открывается шагом обучения;
- `blueprint_or_boss` — чертёж из руин (`science_desk`, `safe`, `crate_military`) или трофей босса;
- дополнительно: рецепт «замечен», когда игрок впервые поднял любой его ресурс тира ≥ 2 → в книге из «неизвестен» становится «известен».
Сохранять множество известных рецептов в сохранении.

### 6.3. Установка станков

Станок — предмет (рецепт на руках/верстаке) → режим установки: призрак спрайта на сетке, зелёный/красный тинт по допустимости (`footprintTiles`, нет пересечений), поворот не нужен. Установленный станок можно разобрать молотком (возврат 50% ресурсов).

### 6.4. Книга крафтов (UI)

1. Вкладки: «Руки» + каждый станок, который игрок видел (иконка — уменьшенный спрайт станка). Рядом со станком открывается вкладка этого станка по умолчанию.
2. Рецепт — карточка: иконка результата, количество, время, ингредиенты с наличием «есть/нужно».
3. Три состояния: **неизвестен** — силуэт (иконка залита тёмным) + подсказка «Найди чертёж в руинах города» / «Победи Тирана»; **не хватает** — недостающее красным, тап по ресурсу → подсказка «Где добыть» из поля `source` предмета или из `biomes.json` (какой объект, каким инструментом, в каком биоме); **можно** — кнопка «Создать» (+ «×5», «Макс»).
4. Фильтры: «Можно сделать», категории (инструменты, оружие, одежда, медицина, еда, постройки, защита, материалы), поиск по названию.
5. Требование навыка показывается замком и названием навыка.

### 6.5. Визуал станков

Костёр: `campfire_unlit` ↔ `campfire_coals` + `effects/flame_1..6` (цикл 0.6 с, ADD) + искры и дым, свет радиус 5. Горн и плавильня: мягкое оранжевое свечение и редкие искры, когда работают. Генератор: лёгкая вибрация спрайта ±1 px и дым. Грядка: стадии `garden_empty → garden_sprouts → garden_ripe` за 1 игровой день.

## Критерии приёмки

- [ ] Полная цепочка пригород → болото без читов: ветки и камни → каменные инструменты → верстак I → ржавые инструменты → верстак II → горн → сталь; медная руда → плавильня → медь.
- [ ] Станок продолжает работу, когда игрок ушёл на 2 чанка и вернулся; при перезагрузке игры прогресс догоняется.
- [ ] Ресурсы берутся из сундуков рядом со станком.
- [ ] Книга показывает три состояния; тап по недостающему ресурсу даёт подсказку «где добыть».
- [ ] Рецепт оружейного стола заблокирован без навыка `engineer_2`.
- [ ] Юнит-тесты крафта проходят.
