# Каталог анимаций и эффектов

Полный список всего, что в игре двигается, светится, трясётся и «отвечает» на действия. Каждый пункт привязан к шагу, в котором его делают, и к ассетам. **Приоритет:** `MVP` — обязательно к первой версии, `+` — желательно, `later` — после релиза.

Все анимации делаются **кодом поверх готовых спрайтов**: tween'ы Phaser, вращение и масштаб вокруг точки привязки, тинт, альфа, частицы, маски. Покадровая анимация — только для эффектов из `assets/effects/`.

## 0. Общие приёмы (реализовать один раз, шаг 3–4)

| Приём | Как в Phaser | Где используется |
| --- | --- | --- |
| **Качание от основания** | `setOrigin(0.5, 1)` + синусоида угла `±A°` с периодом `T` и случайной фазой по позиции объекта (чтобы лес не качался в унисон) | деревья, трава, кусты, столбы, флаги, пугало |
| **«Дыхание»** | `scaleY = 1 ± a`, `scaleX = 1 ∓ a/2`, период 1.5–2.5 с | кусты, звери в покое, боссы, мешки и волдыри врагов |
| **Тряска объекта** | сдвиг `x ± 2 px` 3–4 раза за 0.12 с | удар по объекту, урон стене, работающий генератор |
| **Отскок появления** | масштаб 0 → 1.15 → 1 за 0.25 с (ease back) | дроп, установка постройки, появление UI |
| **Подпрыгивание дропа** | дуга по Y 12 px, 0.35 с, затем лёгкое парение ±2 px | выпавшие предметы |
| **Вспышка урона** | `setTintFill(0xffffff)` на 60 мс, затем красный тинт 0.15 с | любой персонаж и объект с HP |
| **Растворение** | альфа 1 → 0 за 2 с + опускание на 4 px | смерть, исчезновение рюкзака, остатки |
| **Тряска камеры** | `cameras.main.shake(dur, intensity)` | сильный удар, взрыв, таран, рёв босса |
| **Хит-стоп** | пауза логики и анимаций на 40 мс | попадание в ближнем бою, крит |
| **Свечение** | мягкий радиальный спрайт (генерируется кодом) в режиме ADD + пульс альфы | грибы, кристаллы, радиация, лампы, глаза ночью |
| **Пул частиц** | эмиттеры Phaser с кадрами `effects/*` или простыми кругами | пыль, искры, щепки, кровь заменена на слизь |

## 2. Враги и звери (шаг 8, `rigs.json → humanoid / quadruped`)

Общее для всех: idle с дыханием, ходьба/бег, атака, урон (вспышка + отброс), смерть (падение + растворение), появление (см. ниже), элита — масштаб ×1.15, красные глаза с мягким свечением.

| Кто | Особые анимации | Прио |
| --- | --- | --- |
| Бродяга | шаркающая походка (амплитуда ног 60% от героя, наклон вперёд), раскачивание рук; висящий лоскут рубахи (`walker_shirt_flap`) качается | MVP |
| Ползун | ползёт на руках (руки попеременно вперёд, тело подтягивается рывками); в траве невидим — затем «вырастает» из травы с частицами | MVP |
| Болотник | горловой мешок (`spitter_throat_sac`) раздувается 0.6 с перед плевком; плевок — `slime_1` с зелёным тинтом летит по дуге, лужа яда на 3 с | MVP |
| Бегун | спринт с сильным наклоном, выпад-прыжок на героя; поза `sprinter_run_pose` для максимальной скорости | MVP |
| Толстяк | медленное раскачивание; волдыри (`bloated_blisters`) пульсируют свечением; перед смертью раздувается ×1.3 за 0.5 с и взрывается (`explosion_*`, зелёный тинт, лужа кислоты) | MVP |
| Солдат | при 50% HP каска (`soldier_helmet`) слетает по дуге и остаётся на земле; бросок гранаты | + |
| Светящийся | зелёные трещины пульсируют, вокруг аура (`rad_aura`), вспышка при смерти | later |
| Пёс, волк | бег рысью/галопом, кружение вокруг цели, прыжок-укус; волк ночью полупрозрачный вне света | MVP |
| Жаба | прыжки (сжатие перед прыжком), язык (`toad_tongue_and_sac` верхняя часть растягивается по X к цели и обратно), горловой мешок раздувается | MVP |
| Раптор | двуногая походка, хвост балансирует в противофазе, прыжок с когтями | MVP |
| Скорпион | 6 ног волной, хвост с жалом изгибается перед ударом; закапывание — спрайт уходит вниз, остаётся бугорок и пыль | later |
| Броненосец | тяжёлая походка, разгон перед тараном (тряска 0.4 с) | later |
| Олень, заяц | убегание прыжками; заяц — зигзаг, ушки подёргиваются | MVP |
| Кабан | рывок рогами с разгона | MVP |

**Появление врагов** (`+`): ночью заражённые «выходят из темноты» (альфа 0 → 1 за 0.6 с на краю света); днём — вне экрана, без анимации. Кровавая ночь — красная вспышка неба в начале каждой волны.

## 12. Проверка

На каждом шаге в «Критерии приёмки» добавляется пункт: **«все анимации из `ANIMATIONS.md` для этого шага с приоритетом MVP сделаны и видны на записи экрана»**. Отладочная сцена `AnimationGalleryScene` (F7) показывает по кнопке каждую анимацию из каталога: героя, врагов, объекты мира, станки, ловушки, UI.
