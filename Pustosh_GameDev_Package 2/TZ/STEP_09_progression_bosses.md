# Шаг 9. Боссы, прогрессия, транспорт, обучение, сохранения, звук

## Цель

Из песочницы — игра с целью: опыт и навыки, главная линия и ежедневные задания, 6 боссов, открывающих биомы, 7 машин, обучение, карта, полноценные сохранения и звук.

## Входные данные

- `data/bosses.json`, `data/skills.json`, `data/vehicles.json`, `data/biomes.json` (`gate`, `boss`), `data/rigs.json → boss`.
- `assets/characters/bosses/*`, `assets/vehicles/*`, `assets/ui/marker_*`, `clock_day_night`, `icons` трофеев.
- GDD §1, §11–15.

## Задачи

### 9.1. Опыт и навыки

1. XP за: добычу (1 за ресурс тира ≥ 1), крафт (2 × тир), убийство (`xp` врага), первое посещение точки интереса (25), новый рецепт (10), босса (500 × номер). Кривая — `skills.xpCurve`, максимум 40 уровень.
2. Экран навыков: 4 ветки × 6 навыков × 3 уровня, иконки — нужна простая графика кодом (круг + первая буква/символ) или иконки предметов по смыслу (`ASSET_REQUESTS.md`). Сброс навыков — за редкий ресурс (по желанию).
3. Эффекты навыков применяются через модификаторы в системах (урон, износ, радиус подсветки, слоты, скорость станков…).

### 9.2. Боссы (`data/bosses.json`)

1. Арена — префаб из шага 3: круг 9 тайлов, костёр-чекпоинт у входа (возрождение рядом при смерти в бою), вход закрывается стеной-барьером при входе героя.
2. Рендер — `rigs.json → boss`: целый спрайт `idle`, с порога фазы — `phase2`; процедурная анимация (дыхание, наклон к цели, рывки, тряска). Атаки — отдельными частями: крюк Мясника летит к герою, цепь — повтор сегмента; язык Королевы; хвост Тирана; кольцо зубов Пожирателя вращается; осколки «Мороза» веером; щупальца Пациента Ноль (повтор сегмента).
3. Каждая сильная атака — красная зона на земле (полупрозрачный круг/конус/линия с заполнением) за 0.8–1.2 с.
4. Полоса HP босса вверху экрана с именем; фазы по порогам из `phases`.
5. Победа: анимация смерти, трофей (иконка из `trophy.icon`) выпадает предметом, **точка межстраничной рекламы `boss_defeated` перед экраном награды**, экран награды (что открылось: ворота, транспорт, рецепты), **реклама за награду `double_loot`** — второй трофей не даётся, вместо него ×2 ресурсов награды.
6. Ворота биома (`gate`): объект-препятствие; трофей в инвентаре + взаимодействие → ворота открываются навсегда (сохраняется). Флаг `mvpBiomeLimit` закрывает кольца выше лимита табличкой «Скоро».

### 9.3. Задания

1. Главная линия: записки (UI-панель с текстом, агент пишет 12–18 коротких записок по сюжету GDD §1) ведут к боссам, открывают метки на карте.
2. Ежедневные: 3 задания в сутки реального времени из шаблонов («добудь N <ресурс текущего биома>», «убей N <враг> ночью», «скрафти <предмет>»), награда — ресурсы. **Реклама за награду `extra_daily`** — заменить/добавить задание.
3. Журнал заданий и записок в меню.

### 9.4. Транспорт (`data/vehicles.json`)

1. Собирается в гараже (`repair_pit`) из рецепта (агент добавляет рецепты сборки: корпус + детали из лута, согласовать с владельцем).
2. Рендер: корпус + колёса (`wheel`, вращение по пройденному пути: угол = путь / радиус) + для вездехода гусеница `track` с прокруткой UV. Корпус покачивается на неровностях ±1 px. Герой на транспорте не рисуется (сидит внутри) или рисуется верх рига для мото/квадро/велосипеда.
3. Управление: стик/клавиши; инерция, разгон 0.8 с, торможение; проходимость по `terrain` (на чужой местности ×0.3 скорости); топливо из `fuel` (`crude_oil`), расход `fuelPer100Tiles`; HP, ремонт ключом; таран слабых врагов (мото, пикап) — урон от скорости.
4. Багажник (`trunkSlots`) — инвентарь как у сундука. Моды пикапа — спрайты `pickup_armor_kit`, `roof_rack` поверх корпуса.
5. Вызов транспорта к аванпосту за топливо.

### 9.5. Обучение (GDD §15)

8 шагов-подсказок со стрелкой к цели и подсветкой кнопки; шаг засчитывается по событию (поднял ветку, скрафтил топор…). Первая ночь облегчённая (половина спавна). Кнопка «Пропустить обучение». На Яндексе подсказки учитывают раскладку ПК/телефона.

### 9.6. Карта

Экран карты: открытые чанки (туман войны по посещённым), биомы цветом, метки: тотем, аванпосты, места смерти, арены боссов (`ui/marker_boss`), найденные точки интереса (`ui/marker_pin`). Мини-карта в HUD — круг вокруг героя. Из карты — телепорт (шаг 7).

### 9.7. Сохранения

1. `SaveGame`: версия, сид, игровое время, герой (позиция, показатели, инвентарь, экипировка, XP, навыки, известные рецепты), дельты чанков, постройки, станки с очередями, задания, открытые ворота, аванпосты, транспорт, статистика.
2. Сериализация в JSON → сжатие (gzip/deflate) → base64 → `SaveService.save("main", …)`. Размер ориентир < 200 КБ (Яндекс хранит данные игрока с ограничением размера — проверить актуальный лимит в документации и держать запас).
3. Автосохранение раз в 60 с, при выходе в меню, при паузе платформы/сворачивании. Миграции по версии.
4. Юнит-тесты: сохранение → загрузка даёт идентичное состояние; миграция с версии 1.

### 9.8. Звук

Звуковых файлов в пакете нет. Найти бесплатные звуки с лицензией CC0 (шаги, удары по дереву/камню/металлу, выстрелы, взрыв, рык заражённых, интерфейс, костёр, ветер, ночной эмбиент, музыка меню). Каждый файл и его лицензию записать в `assets/audio/LICENSES.md`. Формат: OGG + MP3 (Phaser выбирает поддерживаемый браузером; Safari на iOS играет MP3/M4A). Звук стартует только после первого касания/клика (политика автозапуска браузеров) — первая кнопка «Играть» разблокирует аудио. Громкость по шинам: музыка, эффекты, интерфейс. Звук выключается при любой паузе.
