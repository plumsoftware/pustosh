# Ассеты: каталог, правила, известные дефекты

Все 723 спрайта — PNG с прозрачным фоном, обрезаны по объекту с отступом 2 px. Полный список с размерами — `assets_manifest.json`. Исходные листы — `source_sheets/`, контрольные превью нарезки — `previews/`.

## 1. Стиль и ракурс

- Рисованный полуреалистичный стиль, «немного мультяшные» пропорции, ржавчина, мох, потёртости; свет сверху слева.
- **Объекты мира** — вид как в классических top-down RPG: видны верх и передняя сторона (образец — `tools/angle_reference.png`). Большинство листов 13–16 и интерьер (лист 8) строго «в лоб»; у природы и брошенных машин бывает лёгкая диагональ — это допустимо, они стоят свободно.
- **Персонажи, звери, боссы, транспорт** нарисованы **смотрящими вправо**, сбоку и чуть сверху. Влево — отражение по X.
- **Иконки** — классический ракурс инвентаря 3/4.
- **Тайлы** — строго сверху, бесшовные (проверка — `previews/s06_tiles_repeat3x3.png`).
- **Стены** — две проекции: лицо строго спереди, верх и пол строго сверху (`data/building.json → assembly_rules`).

## 3. Масштаб

ChatGPT рисовал каждый объект на всю ячейку, поэтому **исходные размеры PNG между собой не согласованы**. Целевой размер в игре — поле `targetPx` + `scaleMode` в манифесте:

- `height` / `width` — подогнать эту сторону к `targetPx` (крупные объекты переопределены: деревья 160–200, здания до 224, машины 96–160);
- `fit_box` — вписать в квадрат `targetPx` (иконки 64, эффекты 64 по умолчанию, UI — по макету);
- `exact` — тайлы 64×64;
- `rig` — персонажи: масштаб частей из `data/rigs.json` (доля от роста тела), затем ручная донастройка в редакторе рига (шаг 4);
- `special` — стены: тайл 64, лицо стены 64×48.

На шаге 2 агент делает пайплайн: исходный PNG → ресайз до `targetPx × 2` (для чётких экранов) → упаковка в атласы по группам. Таблица `BIG` в `tools/manifest.py` — стартовые значения, их можно править в манифесте.

## 4. Как собирать персонажей

- Части героя: `pelvis`, `torso`, `head_neutral|head_hurt|head_blink|head_helmet|head_gasmask|head_furhat`, `upper_arm`, `forearm_open|forearm_fist`, `thigh`, `shin_boot`, `backpack`. `ref_idle` и `ref_walk` — эталон пропорций и запасной вариант анимации.
- Дальние рука и нога = те же спрайты, затемнённые тинтом `#9A9A9A` и нарисованные за телом.
- Враги: `<id>_idle|head|torso|pelvis|upper_arm|forearm|thigh|shin|<special>`.
- Звери: `<id>_idle|head|body|front_upper|front_lower|back_upper|back_lower|tail` (у зайца `ears`, у жабы `tongue_and_sac`, у раптора `arm_*`/`leg_*`, у скорпиона `pincer_*`, `leg_*`, `tail_stinger`).
- Боссы: целые спрайты `idle` и `phase2` + отдельные части для атак (`rigs.json → boss`).
- Нижней челюсти отдельно нет (кроме нескольких боссов в архиве): «укус» и «рык» — поворот/сдвиг головы.

## 5. Чем дополнять кодом (картинок нет и не будет)

| Что | Как сделать |
| --- | --- |
| Элитные враги | масштаб ×1.15, красные точки глаз поверх головы, тёмный тинт |
| Позы смерти | поворот idle на 90°, затемнение, исчезновение |
| Снаряды (плевок, камень, сосулька, сфера) | `effects/slime_*`, `devourer_*`, `frost_ice_shard`, `effects/rad_aura` с тинтом |
| Огонь костра, горна, дым, пар, вода из гидранта | `effects/flame_1..6`, `smoke_*`, `dust_*`, `water_splash` поверх спрайта |
| Свет ночью, фонарь, прожектор, свечение радиации | маска освещения (шаг 3), радиальные градиенты |
| Патроны трёх типов | `icons/clothing_mods/ammo_box` + цветная плашка |
| Иконки станков в меню строительства | уменьшенный спрайт станка из `world/interior` |
| Одежда на теле героя | тинт торса по цвету надетой вещи |
| Чертёж | панель `ui/panel_9slice` + иконка предмета поверх |
| Открытая дверь, ворота, повреждения стен | см. `building.json → assembly_rules` |

## 6. Известные дефекты (исправлять кодом, не перегенерировать)

- **Торсы врагов и босса Мясника** — серые круглые «диски» на плечах. Прятать под верхней частью руки (z-порядок).
- **Таз героя** обрезан скриптом до пояса (исходник был «шортами»).
- **`enemies/crawler_forearm_2`** на деле стопа — не использовать; `crawler_ambush_pose` содержит лишнюю руку слева — обрезать по альфе или не использовать.
- **`animals/toad_tongue_and_sac`** — язык и горловой мешок в одном файле: язык — верхние ~25% по высоте, мешок — остальное (разрезать при упаковке атласа).
- **`animals/scorpion_leg_lower`** — два сегмента в одном файле.
- **Колёса мопеда/мотоцикла и корзина велосипеда** — тонкие спицы, возможна лёгкая кайма; при необходимости — `outline 1px` тёмным.
- **Пустыня (`biome4_desert`)**: на тонких балках (вышки, мельница, перекати-поле) слабая фиолетовая кайма от синего фона.
- **Тундра `specimen_tank`** — силуэт в колбе: оставить тёмным/размытым тинтом, чтобы не выглядел как человек в деталях.
- **Эффекты** — 27 кадров: искры 3, пыль 3, дым 2, огонь 6, взрыв 5, вспышка выстрела 2, слизь 2, радиационная аура 1, блёстки 2, всплеск 1.
- **`*_alt` в `icons/base`** — альтернативные иконки (каменный топор и кирка используются как тир 1; ржавый ключ, нож, самодельный пистолет — запасные).

## 7. Если чего-то не хватает

Агент не генерирует картинки. Он делает кодом, а потребность записывает в `ASSET_REQUESTS.md` (что нужно, зачем, где используется, временное решение). Владелец сгенерирует по образцу промптов из `tools/` и пришлёт.
